# FZ Terminal 0.4.2

## Основні зміни

- `Ctrl+C` знову перериває активну команду, зокрема коли ввімкнена українська або інша нелатинська розкладка клавіатури.
- Підказки з історії команд не з’являються, поки foreground-процес виконується, і автоматично відновлюються після повернення до shell.
- Файлові підказки на `Tab` тепер працюють у поточному локальному каталозі та в активних SSH-сесіях.
- Дії з Files pane використовують відповідний локальний або SSH-термінал і не створюють зайве вкладене SSH-з’єднання.
- Автоматично виявлені SSH-підключення зберігають фактично використаний identity file, порт і користувача.
- Popup файлових підказок коректно позиціонується під курсором і обмежується доступною висотою pane.

## Перевірки

- Linux: AppImage і DEB.
- Windows: NSIS installer x64.
- macOS: ZIP для Intel x64 та Apple Silicon arm64.
- Пройдено TypeScript/Vite build, unit tests, ESLint, security scan, terminal context smoke test та `Ctrl+C`/foreground-autosuggest smoke test.
