# FZ Terminal 0.4.3

## Основні зміни

- `Ctrl+C` тепер має контекстну поведінку: копіює виділений текст, а без виділення надсилає переривання активному процесу.
- Розпізнавання `Ctrl+C` працює за фізичною клавішею та не залежить від активної розкладки клавіатури.
- Запис нової комбінації в налаштуваннях повністю ізольований від термінала: шорткат не виконує фонову дію і не перериває активну команду.
- Налаштування шорткатів підсвічує дубльовані комбінації та показує всі пов’язані конфліктні функції.
- Додано окремий перемикач автодоповнення з історії команд. Для нових і наявних профілів воно вимкнене за замовчуванням.
- Автодоповнення з історії команд не з’являється під час виконання foreground-процесу; файлове доповнення залишається окремою функцією.

## Перевірки

- Linux: AppImage і DEB.
- Windows: NSIS installer x64.
- macOS: ZIP для Intel x64 та Apple Silicon arm64.
- Пройдено TypeScript/Vite build, 17 unit-тестів, ESLint, security scan, перевірку SHA256 та наскрізний тест шорткатів, `Ctrl+C` і автодоповнення.
